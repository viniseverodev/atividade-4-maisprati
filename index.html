Projetos

🍕 FoodNow – Cardápio Digital Interativo

Site fictício de um restaurante moderno, com um cardápio online dividido por categorias como pizzas, lanches e bebidas. A ideia é proporcionar uma experiência interativa e responsiva para o usuário, com foco na navegação fluida e nos efeitos visuais.

Tecnologias envolvidas:

HTML, CSS (Flexbox/Grid), JavaScript

🎬 MovieSpace – Catálogo de Filmes

Projeto fictício de um catálogo de filmes, com foco em organização visual e experiência do usuário. O sistema permite pesquisar por filmes e exibe cards com sinopse, imagem e avaliação. Foi pensado para treinar manipulação de dados e organização de layout.

Tecnologias envolvidas:

HTML, CSS, JavaScript

💼 DevJobs – Plataforma de Vagas para Desenvolvedores

Projeto fictício de uma plataforma de vagas voltada exclusivamente para programadores. O objetivo é simular a interface de um site onde empresas podem cadastrar oportunidades e desenvolvedores podem buscar e visualizar vagas por tecnologia, nível e localização.

Tecnologias envolvidas:

HTML, CSS, JavaScript
